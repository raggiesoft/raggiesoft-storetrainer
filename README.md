# RaggieSoft StoreTrainer (`storetrainer.raggiesoft.com`)

The official portal and source code museum for **RaggieSoft StoreTrainer (`TStore.exe`)**—a 100% hand-written (pre-AI, 2018–2020) Win32 desktop utility authored in **Visual Basic 6.0 (`TStore.vbp`)** inside a Windows 2000 Professional SP4 VM (with a `.NET` port `TStore.NET` and NSIS Wizard95 installer `TSSetup.nsi`) to store, index, and launch PC games alongside their associated game trainers (cheat utilities) and command-line arguments across Windows 95 through Windows 11.

- **Production Domain**: `https://storetrainer.raggiesoft.com` (Legacy Installer `301` Redirect: `https://raggiesoft.com/products/storetrainer`)
- **Tech Stack**: Vanilla TypeScript + Classic Win32 / Netscape Communicator 4.7 CSS Static SSG
- **Accessibility**: WCAG 2.1 AA / Section 508 Compliant (`prefers-color-scheme: light | dark` — Win98/2000 Silver & Teal Desktop in Light Mode, Win2000 High-Contrast Dark Terminal in Dark Mode)
